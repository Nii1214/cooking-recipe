# レシピ新規登録とサムネイル画像（読み方）

## 画面から見た流れ（2 ステップ）

1. **画像があるとき** … フォームが `uploadRecipeThumbnailAction` を呼ぶ → サーバーがリサイズして Supabase Storage に保存 → **`path`（例: `{userId}/{uuid}.webp`）** が返る
2. **レシピ保存** … `createRecipeAction` にレシピ本文＋手順＋さっきの **`path`** を渡す → DB にレシピができる

画像が無いときは 1 を飛ばして、2 だけです。

---

## サーバー側の流れ（サムネイルだけ）

```
ブラウザ（FormData に file）
    ↓
uploadRecipeThumbnailAction   … 認証・レート制限・監査ログ・バイト列の受け取り
    ↓
uploadRecipeThumbnailUsecase  … サイズ・MIME などのルールチェック → リサイズ
    ↓
recipeThumbnailImageProcessorImpl  … sharp で長辺 1200px / WebP
    ↓
recipeThumbnailStorageImpl    … Supabase Storage に upload
```

**覚え方**: 玄関（action）→ ルール（usecase）→ 変換（processor）→ 倉庫（infrastructure）。

## 主なファイル

| 役割 | ファイル |
|------|-----------|
| レシピ本体の Action | `action.ts` |
| 画像だけの Action | `upload-recipe-thumbnail-action.ts` |
| 画像のルール | `usecase/recipe/upload-recipe-thumbnail-usecase.ts` |
| 画像の定数（最大サイズ・MIME・リサイズ） | `constants/recipe-thumbnail-upload.ts` |
| 変換の型 | `domain/repositories/recipe/recipe-thumbnail-image-processor.ts` |
| 保存の型 | `domain/repositories/recipe/recipe-thumbnail-storage.ts` |
| sharp 実装 | `infrastructure/image/recipe-thumbnail-image-processor-impl.ts` |
| Storage 実装 | `infrastructure/storage/recipe-thumbnail-storage-impl.ts` |
| 署名 URL | `lib/get-signed-image-url.ts` |
| レート制限・監査ログ | `lib/recipe-thumbnail-upload-controls.ts` |

定数を変えたいときは **`constants/recipe-thumbnail-upload.ts`** だけ見れば足ります。
