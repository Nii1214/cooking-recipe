# 面接想定質問リスト（110 問）

- **対象リポジトリ:** cooking-recipe（食卓手帖）
- **作成日:** 2026-08-12
- **用途:** 自己学習・面接対策。**答えは意図的に書いていない**
- **関連:** [技術リードレビュー](./2026-08-12-tech-lead-review.md)（§6 基礎力マップ / §7 重要度マトリクス）

---

## 使い方

1. 質問を読み、**まず何も見ずに口頭で 30 秒**答えてみる
2. 詰まったら「関連」のファイルを開いて読む
3. 自分の言葉で答えを書く（このファイルに追記してもよいし、別メモでもよい）
4. 「用語は言えるが仕組みが説明できない」ものに印をつけて再訪する

### 難易度の目安

| 記号 | 意味 |
|------|------|
| 基 | 実務 1 年なら答えられてほしい。落とすと痛い |
| 中 | このリポジトリを作った人として答えたい |
| 難 | 答えられると強い。詰まっても致命傷ではない |

### 面接官が見ていること（共通）

- **暗記しているか**ではなく、**選択の理由を説明できるか**
- 「知りません」の後に **どう調べるか** を言えるか
- 自分のコードの **弱点を自覚しているか**
